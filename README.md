# ChatSked 📅💬

> **Turn Facebook chats into confirmed appointments.**  
> *A lightweight, Messenger-native booking engine and CRM built for local service businesses.*

---

### 🚀 What is ChatSked?
ChatSked allows small appointment-based businesses (salons, clinics, repair shops, tutorial centers) to manage bookings effortlessly without asking customers to download an app or change how they communicate. 

Customers book through a fast-loading link right inside Messenger or SMS, while business owners get a real backend calendar, customer records, and automated no-show prevention reminders.

### ✨ Core Features
* 🔗 **No-Login Customer Booking Link:** Fast, mobile-optimized web page designed for patchy mobile data.
* 💬 **Native Messenger & SMS Reminders:** Automated 24-hour and 2-hour appointment reminders to cut down no-shows.
* 🗓️ **Owner/Staff Dashboard:** Mobile-friendly daily calendar, walk-in manager, and schedule control.
* 📋 **Lightweight CRM:** Automatic customer history tracking and repeat-client tagging.
